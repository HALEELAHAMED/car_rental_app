# Car Rental Application

This is a Flutter-based **Car Rental Application** developed as part of a machine task submission.

## Features

* Login and Sign Up (Demo authentication)
* Car Listing with filter chips
* Car Detail Page
* Booking Form with Date Picker
* Booking Confirmation Screen

## Prerequisites

* Flutter SDK installed
* Android Studio or VS Code
* An emulator or a real Android device

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/HALEELAHAMED/car_rental_app.git
   ```
2. Navigate to the project directory:

   ```bash
   cd car_rental_app
   ```
3. Install dependencies:

   ```bash
   flutter pub get
   ```
4. Run the application:

   ```bash
   flutter run
   ```
